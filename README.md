# Параметрический генератор мебели

Автоматическое проектирование мебели с расчётом раскроя, фурнитуры и сметы.

## Возможности
- 3D-визуализация в браузере
- Автоматическая деталировка
- Оптимизация раскроя материала
- Расчёт фурнитуры и метизов
- Смета с разбивкой по статьям
- Экспорт в CSV и DXF

## Технологии
HTML5 · CSS3 · JavaScript · Three.js · jsPDF

## Использование
Откройте `index.html` в браузере или посетите GitHub Pages.
